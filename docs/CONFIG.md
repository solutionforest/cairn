# Tidemark configuration reference

Generated by `tidemark config schema` from `tidemark_core::config` — do not edit by hand.

Every key can be set in `tidemark.toml` (section `[a]`, key `b` for `a.b`) or overridden with
the environment variable `TIDEMARK_<SECTION>_<KEY>` (upper case; arrays comma-separated).
Aliases: `TIDEMARK_ROOT_ACCESS_KEY`, `TIDEMARK_ROOT_SECRET`, `TIDEMARK_DATA_DIR`. Durations accept
`500ms`, `30s`, `15m`, `12h`, `30d`, `1w` or a number of seconds.

## `[server]`

| Key | Default | Description |
|-----|---------|-------------|
| `listen` | `"127.0.0.1:9000"` | Listen address (`ip:port`). |
| `domain` | unset | Base domain for virtual-host-style buckets (`bucket.<domain>`); path style always works. |
| `region` | `"us-east-1"` | Region name reported to clients and stamped on events. |
| `tls_cert` | unset | PEM certificate chain; enables HTTPS together with `tls_key`. Reloaded on SIGHUP. |
| `tls_key` | unset | PEM private key. |
| `shutdown_grace` | `"30s"` | How long in-flight requests may drain after SIGTERM. |
| `trusted_proxies` | `[]` | CIDRs of reverse proxies whose `X-Forwarded-For` / `X-Forwarded-Proto` are trusted (comma-separated in env). |

## `[storage]`

| Key | Default | Description |
|-----|---------|-------------|
| `data_dir` | `"./data"` | Data directory root (`meta/`, `blobs/`, `tmp/`, `keys/`, `audit/`). |
| `fsync` | `true` | fsync blobs before rename (disable only for tests). |
| `verify_on_read` | `false` | Re-hash blobs while streaming GETs. |
| `encrypt_at_rest` | `false` | Encrypt every blob with a key derived from the master key (`storage.master_key`, else `storage.master_key_file`, else `keys/master.key` created on first use). |
| `master_key` | unset | Master key as 64 hex characters; set it with `TIDEMARK_STORAGE_MASTER_KEY` rather than in the file. Never printed by `tidemark config check`. Unset by default. |
| `master_key_file` | unset | File with the master key (32 raw bytes or 64 hex characters), e.g. a container secret; must exist, never generated. Unset by default (`keys/master.key`). |
| `min_free` | `1073741824` | Bytes kept free under the data directory; writes that would eat into it get `507 InsufficientStorage`. `0` disables. |
| `meta_cache` | `0` | Bytes of memory the metadata database may use as page cache. `0` (default) = an eighth of the memory available to the process (container limit or RAM), between 64 MiB and 256 MiB; the server logs the value it picked. Raise it for very large buckets (a cache smaller than the hot metadata costs throughput), lower it on tiny machines. |
| `scrub` | `false` | Run the background scrubber (re-hash blobs, record damage). |
| `scrub_bytes_per_sec` | `52428800` | Scrubber read budget in bytes/s (0 = unthrottled). |
| `scrub_idle` | `"1h"` | Pause between scrub passes. |

## `[retention]`

| Key | Default | Description |
|-----|---------|-------------|
| `soft_delete` | `"30d"` | How long soft-deleted versions stay restorable (server default; per-bucket override via admin API). |
| `shadow_history` | `"30d"` | How long superseded versions are kept for PITR. |
| `min_versions_kept` | `1` | Minimum versions kept per key regardless of age. |
| `gc_grace` | `"1h"` | Delay between a blob's refcount reaching 0 and unlinking it. |
| `gc_interval` | `"1m"` | GC worker interval. |
| `lifecycle_interval` | `"1h"` | Lifecycle worker interval. |

## `[auth]`

| Key | Default | Description |
|-----|---------|-------------|
| `root_access_key` | unset | Bootstrap/reset root access key id (`TIDEMARK_ROOT_ACCESS_KEY`). Optional after `tidemark init`: the root credential lives in the credential store. |
| `root_secret_key` | unset | Bootstrap/reset root secret (`TIDEMARK_ROOT_SECRET`). Never printed by `tidemark config check`. |
| `allow_anonymous` | `false` | Reserved; anonymous access is granted only by bucket policies. |
| `oidc_providers` | `[]` | `[[auth.oidc_providers]]` entries: `issuer`, `audiences`, `jwks_url` or `jwks` (inline JSON string), `claim_tags`. Enables `AssumeRoleWithWebIdentity`. |

## `[limits]`

| Key | Default | Description |
|-----|---------|-------------|
| `max_object_size` | `5368709120` | Largest single PUT in bytes. |
| `max_part_size` | `5368709120` | Largest multipart part in bytes. |
| `min_part_size` | `5242880` | Smallest multipart part (all but the last). |
| `max_parts` | `10000` | Most parts per upload (1..=10000). |
| `max_metadata_size` | `2048` | Largest user metadata in bytes. |

## `[events]`

| Key | Default | Description |
|-----|---------|-------------|
| `enabled` | `true` | Run delivery workers for `[[events.sinks]]`. |
| `sse` | `false` | Serve the live SSE stream at `/_tidemark/v1/events` (every event is recorded in the outbox). |
| `sse_buffer` | `1024` | Events buffered per SSE subscriber before it receives `event: lagged`. |
| `max_attempts` | `8` | Delivery attempts per batch before dead-lettering. |
| `sinks` | `[]` | `[[events.sinks]]` entries: `id`, `url`, `arns`, `auth = { mode = "hmac"\|"bearer"\|"sigv4-lambda"\|"cf-access"\|"none", … }`, `batch_size`, `timeout_secs`. Destination ARN `arn:tidemark:sink::<id>`. |

## `[mcp]`

| Key | Default | Description |
|-----|---------|-------------|
| `enabled` | `false` | Serve MCP over streamable HTTP at `/_tidemark/mcp`. |

## `[metrics]`

| Key | Default | Description |
|-----|---------|-------------|
| `enabled` | `true` | Serve Prometheus metrics at `GET /metrics` (unauthenticated; restrict at the network layer). |
| `stats_interval` | `"5m"` | How often storage gauges (blob count/bytes, live/trash bytes) are recomputed. |

## `[log]`

| Key | Default | Description |
|-----|---------|-------------|
| `level` | `"info"` | `tracing` env-filter directive (`RUST_LOG` wins). |
| `json` | `false` | Emit JSON log lines. |

## `[audit]`

| Key | Default | Description |
|-----|---------|-------------|
| `enabled` | `true` | Write the JSONL audit log (mutating and denied requests, STS calls). |
| `path` | unset | Audit file (default `<data_dir>/audit/audit.jsonl`). |
| `max_bytes` | `104857600` | Rotate the audit file at this size. |
| `keep` | `5` | Rotated audit files kept (`.1` … `.N`). |
| `all_requests` | `false` | Also record successful reads. |

## `[scan]`

| Key | Default | Description |
|-----|---------|-------------|
| `endpoint` | unset | Malware scanner; unset = no scanning. `clamd://host:3310`, `clamd:///path/clamd.sock` or `http://host:port/path` (see OPERATIONS.md "Malware scanning"). |
| `quarantine_bucket` | `"quarantine"` | Infected uploads land here as `<bucket>/<key>` instead of their target; created (versioned) at startup. |
| `max_size` | `104857600` | Objects larger than this many bytes are not scanned; `on_oversize` decides. |
| `on_error` | `"reject"` | `reject` (503) or `allow` (store unscanned) when the scanner is down or times out. |
| `on_oversize` | `"allow"` | `reject` (400 EntityTooLarge) or `allow` (store unscanned) for objects over `max_size`. |
| `timeout` | `"1m"` | Per-object scan timeout. |

## `[backup]`

| Key | Default | Description |
|-----|---------|-------------|
| `dir` | unset | Absolute directory for backup sets made by the running server (`tidemark admin backup`); unset = off. |
| `passphrase_file` | unset | File holding the passphrase that encrypts server-made backup sets; unset = plaintext sets. |
| `include_keys` | `true` | Also save `<data_dir>/keys/` (the at-rest master key) in encrypted sets. |
